#  Urban Noise Pollution Analysis

This project analyzes synthetic data on urban noise pollution across different city zones, time slots, and dates using Python (NumPy, Pandas, Matplotlib, Seaborn).

## Dataset Description

The dataset contains 90 days of simulated noise pollution data, broken down into four time slots per day across four types of urban locations.

### Columns:
- `Date`: Date of measurement
- `Time_Slot`: Time of day (Morning, Afternoon, Evening, Night)
- `Location`: Type of location (Residential, Commercial, Industrial, Park)
- `Noise_Level_dB`: Measured noise level in decibels (simulated)

## Tools Used
- **Python**
  - NumPy
  - Pandas
  - Matplotlib
  - Seaborn

## Key Analysis Performed
- Average noise levels by time of day
- Noise level trends over 90 days
- Comparison across different location types
- Distribution of noise levels per time slot
- Heatmap of average noise levels by time slot and location

## Insights
- Industrial areas have the highest average noise.
- Nights are generally quieter across all locations.
- Parks maintain low noise levels throughout the day.


This project showcases practical data analysis skills using only Python-based libraries and highlights environmental awareness through data storytelling.
